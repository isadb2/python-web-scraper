# Client Offer: Product / Catalog Data Extraction

## What I deliver

A Python scraper that collects public catalog data and returns a clean CSV or Excel file.

Typical fields can include:

- product name
- price
- availability
- rating
- product URL
- SKU/UPC when publicly shown
- category
- description

## Typical workflow

1. Client provides a public target URL and the fields needed.
2. I confirm the page structure and scope.
3. I build a small scraper with retries, timeouts and request pacing.
4. I validate a sample of the extracted rows.
5. I deliver CSV/XLSX plus the Python source code when requested.

## Scope boundary

I do not bypass logins, CAPTCHAs, paywalls, anti-bot systems, or other access controls. The target website must permit the requested collection and use of public data.
